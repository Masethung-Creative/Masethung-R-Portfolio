## The problem

SFJ needed a single place to manage internal data that had been spread across
spreadsheets and disconnected tools. Teams across five business verticals were
each tracking things their own way, which meant no one had a reliable view of
anything.

## What I did

I led the design end to end as the only designer on the project.

**Wireframes.** Started with the data model and the tasks people actually
repeat — search, filter, bulk edit — and laid out low-fidelity screens before
touching visual design. This is where most of the arguing happened, which is
where it should happen.

**Visual design.** Built the interface on a component set so screens stayed
consistent as scope grew. Dense data tables were the hard part: enough
information to be useful, enough breathing room to be readable.

**Launch.** Designed the social creatives and promotional posts that announced
the tool internally.
